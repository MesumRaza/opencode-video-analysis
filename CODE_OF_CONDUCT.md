# Code of conduct

This project follows the **Contributor Covenant, version 2.1**
(<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>). The short
version, which is the part that matters here:

## Expected

- Be direct about code and kind about people. Review the change, not the person.
- Assume competence. Ask “what did you see?” before “what did you do wrong?”.
- Credit other people's work — in commits, in the changelog, in a comment.
- Accept that the maintainer decides scope. “Not now” is a complete answer, and
  a fork is a legitimate response to it.

## Not acceptable

- Harassment, insults, or sexualised attention of any kind.
- Discriminatory comments about identity, background, experience level or
  language ability. This project is used and written by non-native English
  speakers; correct the code, not the accent.
- Publishing someone's private information without permission, including API
  keys, file paths or personal video content.
- Sustained disruption: reopening settled decisions, derailing issues, or
  campaigning against a licence decision that is already documented.

## Scope

Issues, pull requests, discussions, commit messages, and any space where you are
representing the project.

## Enforcement

Report a problem privately to the maintainer through
<https://github.com/mesumraza> (or by opening a minimal issue asking for a
private channel, without details). Reports are read by the maintainer only.

Responses, in order of severity: a private word; a public correction; a
temporary block from the repository; a permanent ban. The maintainer will not
mediate disputes about the AGPL or the commercial licence — those are settled
policy, documented in [LICENSE](./LICENSE) and [COMMERCIAL.md](./COMMERCIAL.md).
